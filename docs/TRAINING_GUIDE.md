## 1. Все флаги командной строки (CLI Flags)

Команда запуска режима обучения:
```bash
cargo run --release -- --train [generations] [population] [duration] [flags...]
```

### Основные позиционные и именованные аргументы:

| Флаг / Позиция | Тип / Значения | По умолчанию | Описание |
| :--- | :--- | :--- | :--- |
| `--train [G] [P] [D]` | `G: usize, P: usize, D: f32` | `8 8 Auto` | Запуск режима со-эволюции (Self-Play). `G` — число поколений, `P` — размер популяции (мин. 3), `D` — лимит матча в секундах. |
| `--bosses N` / `--boss-count N` | `usize (1..8)` | `1` | Число одновременно живых боссов на арене (кооперативный режим). |
| `--1020` / `--full` | флаг | выкл | Задать длительность всех раундов в **1020 секунд (17 минут)** — полный матч. |
| `--300` / `--fast` | флаг | выкл | Задать длительность всех раундов в **300 секунд (5 минут)** — быстрый раунд. |
| `--cap N` / `--duration N` | `f32 (секунды)` | `None (Curriculum)` | Фиксированная длительность матча в секундах (например, `--cap 600`). |
| `--think-ms N` | `50`, `100`, `200` | `200` | Частота принятия решений нейросетью Босса в миллисекундах (`0.2 с` = 5 Гц). |
| `--clean` / `--reset` | флаг | выкл | Полный сброс моделей: начать обучение с нуля (поколение #0, случайные веса). |

### Флаги Островной Модели (Island Model):

| Флаг | Тип / Значения | По умолчанию | Описание |
| :--- | :--- | :--- | :--- |
| `--island <NAME>` | `String` | `"local"` | Уникальное имя текущего узла/устройства (например, `desktop_i3`, `laptop_i5`, `laptop_ryzen`). |
| `--exchange <PATH>` / `--island-dir` | `Путь к папке` | `None` | Путь к общей директории для обмена чемпионами (локальная сетевая папка, папка Syncthing/диска). |
| `--migrate-every <N>` | `usize` | `10` | Каждые $N$ поколений экспортировать своего чемпиона и импортировать чемпионов других островов. |

### Флаги мультиплеера и интерфейса игры:

| Флаг | Тип | Описание |
| :--- | :--- | :--- |
| `--host [BIND]` | `IP:Port` (по умолч. `0.0.0.0:45678`) | Запуск игры в режиме сетевого UDP хоста (Директор). |
| `--connect <ADDR>` | `IP:Port` | Подключение к сетевой игре в роли Босса. |
| `--boss-player` | флаг | Запуск локальной игры сразу за Босса-игрока (без Директора). |
| `--match-minutes N` | `1.0..180.0` | Длительность матча в минутах для сетевой игры. |
| `--boss-levelup` | отладка | Принудительно вызвать меню выбора перка на 10-м кадре. |

## 2. Горячие клавиши управления (Hotkeys)

### Директор (Стратегический режим):
- **Переключение страниц мобов:**
  - `[ 1 ]` — Страница 1: **Базовая Орда** (Тиры 1–8).
  - `[ 2 ]` — Страница 2: **Высший Легион** (Тиры 9–16).
  - `[ Tab ]` — Циклическое переключение страниц (1 ⇄ 2).
- **Призыв отрядов мобов:**
  - `Q, W, E, R, A, S, D, F` — призыв 1 отряда соответствующего слота на активной странице.
  - `Shift + [Q..F]` — **«Призыв на ВСЕ души»** (тратит весь запас душ на максимальное число отрядов).
- **Строительство Алтарей Крови:**
  - `Ctrl + [Q..F]` — мгновенный выбор Алтаря соответствующего тира с текущей страницы:
    - На странице 1: `Ctrl+Q` (тир 1), `Ctrl+W` (тир 2), `Ctrl+E` (тир 3), `Ctrl+R` (тир 4)...
    - На странице 2: `Ctrl+Q` (тир 9), `Ctrl+W` (тир 10), `Ctrl+E` (тир 11), `Ctrl+R` (тир 12)...
  - Под каждой карточкой моба отображается кнопка Алтаря с ассетом `structure_altar`, бейджем хоткея `^Q..^F` и ценой.
  - **Индикация доступности:** Когда алтарь готов к постройке (хватает душ, нет перезарядки), кнопка **пульсирует неоновым багряно-золотым свечением (Glow)**. При наведении мыши всплывает подробный тултип со всеми характеристиками, аурой исцеления и доходом.
  - `ЛКМ` на карте — установить выбранный алтарь по сетке арены.
  - `ПКМ / Esc` — отмена режима постройки.
- **Строительство Баррикад (Стен):**
  - Клавиша `B` или кнопка в UI — войти в режим установки каменной стены.
- **Грейды армии Директора:**
  - `Z` — Ярость (+12% физ. урона, +8% скорости атаки), `Shift+Z` — на все очки.
  - `X` — Панцирь (+0.8 брони, +5% сопротивления), `Shift+X` — на все очки.
  - `C` — Чумные споры (+7 яда, замедление при гибели), `Shift+C` — на все очки.
- **Досье и Кодекс:**
  - `I` — открыть Кодекс знаний.
  - Клик по кнопке `[ i ]` на любой карточке моба или предмета — открыть подробное тактическое досье.
  - `Esc` — закрыть окно / снять сетевую паузу.

### Босс (Экшен-режим):
- **Управление:**
  - `WASD` — классическое прямое управление перемещением.
  - `F2` — переключение режима управления: **WASD** ⇄ **ПКМ RTS** (с кликами мыши и клавишей `S` для стопа).
  - `Пробел` — Экстренный рывок (Dash): рывок на 260 px с уроном врагам, снятием снарядов и деактивацией обелисков.
- **Выбор реликвий и улучшений (Level-Up):**
  - Цифры `[ 1 ]`, `[ 2 ]`, `[ 3 ]` на клавиатуре или `ЛКМ` клик по карточке — выбор карты улучшения/реликвии.

## 3. Островная модель обучения (Island Model на 3 устройства)

Островная модель обучает на каждом устройстве **независимую популяцию** со своими случайными мутациями и селекцией. Каждые `--migrate-every` поколений лучшие чемпионы экспортируются в общую папку, а чемпионы с других компьютеров импортируются и интегрируются в **Зал Славы (League Hall of Fame)** и в популяцию (замещая слабейших агентов).

### Схема обмена через общую папку:
```
           [ Папка обмена: Syncthing / SMB Share / Git / Флешка ]
                ▲                     ▲                    ▲
                │ (каждые 10 раундов) │                    │
                ▼                     ▼                    ▼
        ПК (i3-10100F)       Ноутбук 1 (i5-1035G1)   Ноутбук 2 (Ryzen 7520U)
        Остров: desktop_i3   Остров: laptop_i5      Остров: laptop_ryzen
```

### Команды запуска для каждого устройства:

#### 1. Основной ПК (Intel Core i3-10100F, 4 ядра / 8 потоков):
Создаем общую сетевую папку (например, `D:\anti_vs_exchange` и расшариваем её в Windows по сети под именем `\\DESKTOP-MAIN\exchange`):
```powershell
cargo run --release -- --train 100 8 --1020 --bosses 1 --island desktop_i3 --exchange "D:\anti_vs_exchange" --migrate-every 10
```

#### 2. Ноутбук в общей локальной сети (Intel Core i5-1035G1, 4 ядра / 8 потоков):
Подключается к сетевой папке ПК:
```bash
# В Windows:
cargo run --release -- --train 100 8 --1020 --bosses 1 --island laptop_i5 --exchange "\\DESKTOP-MAIN\exchange" --migrate-every 10

# В Linux (если смонтирована Samba или Syncthing):
./Anti_VS --train 100 8 --1020 --bosses 1 --island laptop_i5 --exchange "/mnt/exchange" --migrate-every 10
```

#### 3. Ноутбук вне локальной сети (AMD Ryzen 5 7520U, 4 ядра / 8 потоков):
Если ноутбук не в общей сети, самый простой и надежный способ — использовать бесплатный инструмент синхронизации **Syncthing** (работает через интернет без белого IP и проброса портов), либо синхронизацию через приватный репозиторий Git / папку Яндекс.Диск / Google Drive:
```powershell
cargo run --release -- --train 100 8 --1020 --bosses 1 --island laptop_ryzen --exchange "C:\Syncthing\anti_vs_exchange" --migrate-every 10
```

## 4. Максимальная настройка ноутбука i5-1035G1 (8 GB RAM) под обучение

Процессор **Core i5-1035G1** (архитектура Ice Lake, 10 нм, 4 ядра / 8 потоков, AVX-512, 15W TDP) при правильной настройке выдает потрясающую скорость в headless-симуляциях Rayon.

### Шаг 1: Операционная система (Рекомендуется Linux Server)
Если ноутбук используется чисто под обучение, переход на **Ubuntu Server 24.04 LTS** (или Debian 12 / Arch Linux) **БЕЗ графического окружения (GUI)** даст колоссальный прирост:
- Экономия ОЗУ: система потребляет всего ~150 МБ RAM вместо 3–4 ГБ в Windows 11. Все оставшиеся ~7.7 ГБ отдаются Rayon под симуляции.
- Отсутствие фоновых служб Windows (Windows Defender, телеметрия, обновления), которые съедают 15–25% CPU и греют ноутбук.

### Шаг 2: Настройка CPU Governor на максимум производительности (в Linux)
Ноутбучные процессоры агрессивно сбрасывают частоты в энергосбережение. Принудительно зафиксируйте режим `performance`:
```bash
sudo apt update && sudo apt install -y cpufrequtils linux-tools-generic

# Включаем режим максимальной производительности на всех 8 потоках
sudo cpupower frequency-set -g performance
```

### Шаг 3: Включение ZRAM (сжатие RAM вместо медленного дискового свопа)
При 8 ГБ RAM zram создаст в памяти сверхбыстрый сжатый диск (алгоритм zstd), исключая просадки ввода-вывода SSD:
```bash
sudo apt install -y zram-tools
echo -e "ALGO=zstd\nPERCENT=50" | sudo tee /etc/default/zramswap
sudo systemctl restart zramswap
```

### Шаг 4: Аппаратная оптимизация компиляции Rust под Ice Lake
В процессоре i5-1035G1 есть инструкции **AVX-512** (F, CD, BW, DQ, VL) и **VNNI**!
Стандартный бинарник `cargo build --release` компилируется под базовый x86-64 и не использует AVX-512.
Если скомпилировать бинарник с флагом `target-cpu=native` непосредственно на ноутбуке, Rayon и нейросетевые dot-product циклы ускорятся на **30–50%**:
```bash
# Установка Rust:
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
source $HOME/.cargo/env

# Сборка с оптимизациями под родной процессор:
RUSTFLAGS="-C target-cpu=native" cargo build --release
```

### Шаг 5: Непрерывное обучение в фоне через `tmux` / `screen`
Чтобы закрытие крышки ноутбука или отключение SSH не останавливало обучение:
```bash
# В файле /etc/systemd/logind.conf:
# HandleLidSwitch=ignore (ноутбук не засыпает при закрытой крышке)
sudo systemctl restart systemd-logind

# Запуск в tmux:
tmux new -s training
./target/release/Anti_VS --train 500 8 --1020 --bosses 1 --island laptop_i5 --exchange "/mnt/exchange" --migrate-every 10
# Нажмите Ctrl+B, затем D, чтобы отсоединиться (обучение продолжит работать в фоне)
```
