# Комплексный отчет: Эволюция ИИ и оптимизация Anti_VS

В данном документе зафиксированы все ключевые архитектурные решения, изменения алгоритмов ИИ, математические формулы фитнеса и оптимизации производительности движка, выполненные в ходе работы над проектом.

---

## 1. Новая сенсорная система Босса (150 входов)

### Предыстория и проблема
Ранее Босс использовал грубую 8-секторную круговую модель («ромашка»), где снаряды и мобы сливались в общую массу. Босс не мог видеть безопасные коридоры между летящими снарядами и не различал угрозу от дальних снайперов за пределами экрана.

### Архитектура Dual-Ring Sensor Grid
Разработана и внедрена гибридная система наблюдения из 150 скалярных признаков:
```
+---------------------------------------------------------+
|     ВНЕШНИЙ МАКРО-ПОЯС (16 секторов, радиус 500 px)      |
|                                                         |
|         +-------------------------------------+         |
|         |  ВНУТРЕННЯЯ СЕТКА (11x11, 50 px)     |         |
|         |  Охват 550x550 px вокруг Босса      |         |
|         |  - Снаряды (вес 2.5x)               |         |
|         |  - Ближние мобы                     |         |
|         |             [ БОСС ]                |         |
|         +-------------------------------------+         |
|                                                         |
|  - Директ-векторы на культистов и снайперов             |
+---------------------------------------------------------+
```

1. **Внутренняя локальная сетка ($11 \times 11 = 121$ ячейка, шаг 50 px, охват $550 \times 550$ px)**:
   * Каждая ячейка суммирует угрозы: мобы + летящие снаряды (с приоритетным множителем $2.5\times$).
   * Дает пространственное микро-зрение для ювелирного стрейфа между снарядами культистов и камикадзе.
2. **Внешний макро-пояс (16 секторов, дальность до 500 px)**:
   * Фиксирует плотность снайперов и дальнобойных культистов, готовящих залп издалека.
3. **Стратегические скаляры навигации (13 входов)**:
   * Координаты и расстояние до центра арены ($dx, dy, dist$).
   * Дистанции отталкивания от 4 силовых границ арены (220 px буфер).
   * Прогресс раунда ($time / 1020$).
   * Текущее состояние здоровья Босса ($HP / MaxHP$).
   * Статус медитации ($timer / 3.0$).
   * Вектор собственной скорости движения.

## 2. Полная автономия решений ИИ (Удаление эвристик)

Ранее часть ключевых решений принималась захардкоженными правилами (`if/else`). Они были полностью удалены в пользу обучения с подкреплением (RL):

* **Тактическая медитация**: Удалены искусственные флаги `wants_meditation = true` (например, "медитировать если Full HP и мобов < 3"). Решение о медитации передано под прямое управление нейросетью.
* **Автономия рывка (Dash)**: Убран костыль `mobs_in_close_radius >= 4`. Рывок активируется нейросетью, а направление определяется вектором уклонения и физикой потенциальных полей.
* **Драфт перков (Perk Draft)**: Удалены костыли прокачки («если мало HP -> брать GiantHeart», «если бьют вблизи -> LightArmor»). Выбор перков теперь на 100% управляется ДНК-весами 6 синергетических архетипов:
  1. *Инфернальный Пиромант* (Огонь, Пламя, Сердце Пироманта)
  2. *Сверхпроводящий Громовержец* (Молния, Тесла, Лира, Клевер)
  3. *Несокрушимый Бастион* (Орбиты, Молот, Щиты, Эгида)
  4. *Аннигилятор Бездны* (Луч Смерти, Сингулярность, Око Колосса)
  5. *Кровавый Жнец* (Топор, Кинжалы, Вампиризм, Клевер)
  6. *Звёздный Охотник* (Лук, Ракеты, Самонаведение, Орлиный Глаз)

## 3. Детализированная телеметрия урона

В модуль `src/ecs/components/inventory.rs` внедрена структура детального учета урона:
* **Категории источников (`DamageSourceKind`)**: `Melee` (контактные атаки мобов), `Ranged` (стрелы, файрболы, снаряды), `Hazard` (кислотные лужи, споры, взрывы камикадзе).
* **Типы повреждений (`DamageTypeBreakdown`)**: Физический, Огонь, Холод, Яд, Святой, Чистый урон.
* Данные выводятся в лог раунда, что позволяет мгновенно видеть причину гибели Босса.

## 4. Оптимизация производительности игры и симуляции

1. **Условный параллелизм (`is_headless`) в `src/ecs/systems/movement.rs`**:
   * *В режиме обучения (Headless)*: симуляции идут параллельно по ядрам CPU (`into_par_iter()`), устраняя накладные расходы Rayon на создание подзадач внутри мира.
   * *В интерактивной игре*: включается `par_iter_mut()`, задействуя все потоки процессора для отрисовки тысяч мобов.
2. **Frustum Culling (Отсечение невидимого)**:
   * В `src/render/renderer.rs` добавлена проверка попадания объектов в экран камеры `in_view(pos, radius)` (сокращение вызовов отрисовки на 60–80%).
3. **Кластеризация кристаллов душ (Soul Gem Clustering)**:
   * При превышении лимита кристаллов на карте близколежащие кристаллы объединяются в крупные кластеры с полным сохранением накопленного XP.

## 5. Вычислительные мощности: Локальная архитектура (Intel Core i3, 8 потоков Rayon)

Симуляция со-эволюции переведена на полностью автономный локальный многопоточный движок на базе **Rayon** и прямого параллелизма CPU. Все вычисления производятся локально на машине пользователя без внешних облачных зависимостей:

| Параметр | Описание локального вычислительного окружения |
| :--- | :--- |
| **Процессор** | **Intel Core i3** (8 аппаратных потоков Rayon) |
| **Архитектура движка** | Pure Rust Headless Simulation + Rayon Multithreading |
| **Параллелизм** | Внешний пул параллельных матчей `into_par_iter()` на все 8 потоков |
| **Кэширование ИИ** | Тактические решения на частоте 5 Гц (в 4 раза быстрее при сохранении точности) |
| **Аллокации памяти** | Zero-Allocation в горячих циклах физики и коллизий (`query_nearby_into`) |
| **Лимиты и стабильность** | Без таймаутов, без разрывов сессий, моментальное сохранение моделей в `models/` |

## 6. Устранение Reward Hacking (Взлом наград) и баланс со-эволюции

### Обнаруженная проблема
В ходе анализа логов раунда было замечено, что Директор затягивал бой до 11.7 минут вместо быстрого добивания. Причина: Директор получал очки за суммарный урон (`damage * 0.06`). Раскармливая регенерирующего босса, Директор набивал **39,000 HP урона** и получал **+2341 очко фитнеса**, что перекрывало штраф за затяжку.

### Корректировки наград
1. **Бонус за ранний конец матча (Блицкриг)**: множитель сохраненного времени поднят с 3.0 до **5.0** (до 5,100 очков). Бонус за убийство повышен до **1,500** очков.
2. **Ужесточение штрафов за затягивание боя**: порог опущен до **5 минут (300с)**. Ставка штрафа увеличена до **-4.0 очка в секунду**.
3. **Потолок на урон**: награда за урон ограничена жестким потолком в **500 очков**, устраняя эксплойт фарма регенерации.

## 8. Переход Босса на 100% чистый End-to-End Reinforcement Learning

### Предыстория и демонтаж эвристик
Ранее в движении Босса оставались остатки потенциальных полей (силы отталкивания от мобов и стен, притяжение к кристаллам). Они создавали конфликт между желанием нейросети и навязанной математикой.
* **Полный демонтаж**: Векторы потенциальных полей удалены из расчёта кинематики. Босс стал чистым нейросетевым агентом.
* **Изоляция телеметрии**: Разделены счётчики чистого пройденного пешком расстояния (`walked_distance`) и перемещения рывками (телепортации больше не засчитываются в шаги).
* **Баланс DoT-эффектов**: Спам кислотных луж, создававший микрофризы, заменён на яд при контакте и токсичные миазмы Алтарей Крови.

## 9. Сенсорная система Директора и Алтарный индекс выживаемости

1. **Метрика удержания Алтарей Крови**:
   * Для предотвращения бессмысленного спама алтарей прямо под ноги Боссу введена формула:
     $$\text{Награда} = \frac{\text{Суммарные секунды жизни всех алтарей}}{\text{Прошедшие минуты матча}} \times 2.5$$
   * Директор замотивирован размещать алтари в труднодоступных местах и защищать их армией.
2. **Расширение восприятия Директора (132 сенсора)**:
   * Выделено **16 отдельных сенсоров** присутствия каждого тира мобов ($T1..T16$) на поле боя.
   * Добавлены сенсоры опыта Босса: текущий уровень, процент прогресса ($\frac{XP}{\text{XP\_next}}$), необходимый остаток XP.
   * Добавлены строгие булевы флаги: Босс в рывке, рывок готов, Босс в медитации, Босс отравлен.
3. **Коррекция границ постройки**:
   * Маргин размещения алтарей снижен со 140 px до 35–45 px от стен, снято искусственное ограничение на максимум 8 алтарей.

## 10. Мозг Директора (`DirectorBrainNet`): от таблицы весов к глубокому ИИ

### Проблема «Петли нищеты» (Poverty Loop)
Ранее Директор выбирал мобов по статической таблице float-весов. При первой попытке внедрить нейросеть с отдельными головами для Спавна и для Апгрейдов возникла коллизия бюджета:
* Голова апгрейдов видела 100 доступных очков и тут же тратила их на 1 уровень Ярости.
* Счётчик душ сбрасывался в 0. В итоге Директор **никогда не мог накопить 2500 очков** на призыв элитных отрядов (Камикадзе, Демоны, Големы, Жнецы).

### Решение: Единая Голова Экономики (Unified Economic Head) + Action Masking
В архитектуре `DirectorBrainNet` спавн и прокачка объединены в одну дискретную голову на 20 выходов:
* `0`: Пас / Накопление душ (стратегическое удержание бюджета).
* `1..=16`: Целевой призыв отрядов $T1..T16$.
* `17`: Грейд Ярости (+15% к урону мобов).
* `18`: Грейд Панциря (+20% к здоровью мобов).
* `19`: Грейд Чумных спор (ядовитый урон).

**Invalid Action Masking (RL Best Practice)**:
Перед операцией `argmax` тиры мобов, порог разблокировки которых ещё не достигнут по сумме потраченных очков (`total_points_spent < unlock_spent_threshold`), принудительно маскируются (`f32::NEG_INFINITY`). Директор не может заблокироваться на недоступном Тире 10 на старте матча — он начинает с доступных действий, открывая новые тиры по мере прогресса.

## 11. Глобальный рефакторинг по итогам внешнего аудита (Архитектура 2.0)

В результате всестороннего аудита системы ИИ была проведена масштабная модернизация (более 2100 строк улучшений):

### 1. Честный Zero-Sum Reinforcement Learning
* **Единая полезность `director_utility`**:
  $$\text{Utility} = \text{TimeReward (600)} + \text{KillBonus (400)} + \text{DamageShare (200)} + \text{AltarUptime (150)} + \text{EconomyEfficiency (50)} - \text{BossLevel (100)}$$
  * Директор максимизирует `+director_utility`.
  * Босс максимизирует `-director_utility`.
  * Полное исключение возможности негласного сговора (когда Босс кайтит ради выживания, а Директор спамит алтари ради аптайма).
* **Ликвидация искусственного пола `.max(10.0)`**: Фитнес стал строго дифференцируемым, турнирная селекция получила чистый градиент в нижней половине популяции.
* **Починен Resume**: Реальный фитнес чемпионов сохраняется при повторном запуске, исключена случайная перезапись слабыми моделями.
* **Общая турнирная матрица и детерминированные сиды**: Босс и Директор оцениваются в одних и тех же матчах на общих сидах. Результаты строго воспроизводимы.
* **Curriculum Learning**: Стартовая длительность матчей снижена до 300 секунд, плавно масштабируясь к 1020 секундам по мере роста поколений.

### 2. Сенсоры 2.0 (Ликвидация алиасинга)
* **Босс (150 входов)**:
  * Внутренняя сетка 5×5 разделена на **4 независимых канала**: [0] Мобы, [1] Снаряды Директора, [2] Опасные зоны (миазмы/лужи), [3] Стены арены.
  * Добавлены метрики Time-To-Impact (TTI) и бокового смещения для летящих снарядов для ювелирного уклонения.
  * Явные сенсоры кулдауна рывка и статуса медитации.
* **Директор (132 входа)**:
  * Удалены 68 бесполезных сырых уровней оружия Босса.
  * Внедрена **4×4 пространственная карта плотности собственной армии** (Директор видит, где сгруппированы его войска).
  * Введены 8 агрегированных оценок боевой мощи Босса (DPS, выживаемость, синергии) и сенсоры доступности отрядов.

### 3. Действия 2.0
* **Босс (7 выходов)**:
  * Непрерывная скорость движения (`OUT_MOVE_MAG`: от 0.0 до 1.0) вместо грубого 100%/0%.
  * **Независимый вектор направления рывка (`OUT_DASH_X`, `OUT_DASH_Y`)**: Босс может отпрыгивать назад, продолжая стрелять вперёд.
  * Осознанный канал намерения медитации (`OUT_REST`).
* **Директор (3 головы)**:
  * Добавлена **голова тактического призыва на 8 секторов вокруг Босса** (`DIRECTOR_SPAWN_HEAD_SIZE = 8`). Директор осознанно окружает Босса или бьёт во фланг.
  * Алтари дискретизированы в устойчивую сетку 5×5 слотов с обязательной проверкой валидности позиции.

### 4. Экстремальное ускорение симуляции (~4–5x)
* **Кэширование тактических решений Босса (5 Гц)**: Мысли Босса обновляются раз в 0.2 сек, физика мира работает на 20 Гц. Скорость обучения выросла в ~4 раза без потери качества.
* **Ноль аллокаций в горячих циклах**: Метод `query_nearby_into` переиспользует буфер, исключая миллионы мелких аллокаций `Vec`.
* **Быстрая кластеризация кристаллов**: Алгоритм слияния кристаллов душ переписан с $O(N^2)$ на $O(N)$ пространственную сетку.
* **Быстрый расчет урона**: Замена линейного поиска жертвы $O(N)$ на $O(1)$ хэшмап индексов.
* **No-Op эффекты**: Полное отключение партиклов, звуков и плавающего текста в headless-режиме.
* **Кэш модели Босса**: Модель читается с диска 1 раз за сессию, а не на каждом матче.

## 13. Финальная полировка Архитектуры 2.0 и гибкие регламенты раундов

1. **Гибкий выбор регламента матчей (300 сек vs 1020 сек)**:
   - В симулятор со-эволюции добавлен селектор длительности через CLI:
     - `cargo run --release -- --train 20 16 300` (или флаги `--cap 300` / `--fast`).
     - `cargo run --release -- --train 20 16 1020` (или флаги `--cap 1020` / `--full`).
   - Позволяет как быстро проводить мутационные итерации на 5-минутных спринтах, так и тестировать агентов в полном 17-минутном лейтгейме со всеми эволюциями оружия.
2. **Снятие искусственных кулдаунов призыва у Директора**:
   - Из логики `DirectorBrainNet` убрана блокировка спавна по таймерам отрядов (`squad_cooldowns`). Теперь Директор ограничивается исключительно экономикой казны и стоимостью вызова.
3. **Исправление застревания урона яда (`boss_poison_dps`)**:
   - В системе передвижения исправлена ошибка, при которой максимальный урон яда сохранялся после окончания действия ядовитых миазм. Теперь при истечении таймера яда `world.boss_poison_dps` гарантированно сбрасывается в 0.0.
4. **Нормализация сенсора алтарей**:
   - В `src/ai/sensors.rs` при отсутствии активных алтарей сенсор ETA (`obs[138]`) теперь возвращает дефолтное нейтральное значение `1.0` (аналогично сенсору магнитов `obs[142]`), устраняя шум для нейросети Босса.
5. **Локальная пространственная сетка слияния кристаллов ($140 \times 140$ px)**:
   - Шаг 2 алгоритма слияния избыточных кристаллов переведён на локальную пространственную сетку $140 \times 140$ px, исключая мгновенную телепортацию XP через всю арену к случайным кристаллам.
6. **Очистка репозитория**:
   - Удалены временные архивы и блокноты Google Colab, а также дублирующие дампы нейросетей (`boss_brain_neural.json`, `director_brain_neural.json`). Все веса сохраняются в эталонных файлах `models/boss_policy.json` и `models/director_policy.json`.

## 14. Система Баррикад, 4 Угловых Инфернальных Разлома и Редизайн Управления (Версия 2.2)

1. **Защитные Стены-Баррикады (50x50 px)**:
   - Внедрена разрушаемая структура `STRUCTURE_WALL` (350 HP, 14 брони, 50% защиты от холода, иммунитет к яду).
   - Стоимость 10 душ, кулдаун 2.0 сек, время жизни 60.0 сек (с графическим таймером распада).
   - Полноценная физическая коллизия: Босс не может пройти сквозь стену (выталкивание на радиусе 43.0 px) и вынужден огибать её либо таранить. Рывок Босса наносит 160 урона структурам. Слом стены дает Боссу +15 XP.
   - Быстрый вызов на клавишу `[B]` или через UI-виджет `🧱 СТЕНА [B]`.

2. **4 Древних Угловых Разлома / Обелиска (300x300 px)**:
   - Расположены в фиксированных углах арены: `(260, 260)`, `(2940, 260)`, `(260, 2940)`, `(2940, 2940)`.
   - Графика: монолитные обелиски в спящем состоянии и инфернальные порталы с вортексом пустоты, рунами и молниями в активном.
   - Цикл 60 секунд: один из обелисков активируется и заряжается 20 секунд (`state_timer = 20.0`).
   - ИИ Босса переключается на наивысший приоритет движения и атаки (вес 240.0), стремясь сорвать ритуал.
   - **Успех Босса**: слом разлома до истечения 20с дарует +350 XP, глобальный магнит кристаллов (Screen Magnet) и моментальное лечение +15% от максимального HP. Обелиск не исчезает, а засыпает до следующего цикла.
   - **Инфернальный Прорыв**: если Босс не успел за 20с, разлом открывает врата и спавнит элитную орду по формуле `(инкам душ + алтари * 3.0) * 15.0`.

3. **Ребаланс Алтарей Крови**:
   - Кулдаун снижен до 14 секунд (вместо 60с). Стоимость 50 душ.
   - Каждую секунду порождает 1 скелета. Каждые 3 секунды лечит союзников на +35 HP в радиусе 160 px. Каждые 2 секунды приносит +3 души.
   - Формула пряников в конце раунда переведена на зависимость от секунд жизни босса / 14 с нормализующим коэффициентом (не более эквивалента 17 алтарей за 1020с).

4. **Защита Медитации Босса**:
   - Зона отключения медитации увеличена до 300 пикселей (присутствие мобов в 300 px блокирует медитацию).
   - Внедрен таймер недавнего урона: медитация блокируется на 3.0 секунды после получения любого урона.

5. **Эргономичная раскладка клавиатуры**:

   - Страницы мобов: переключение не только на `[Tab]`, но и на прямые цифровые клавиши `[1]` (Орда) и `[2]` (Легион).

## 15. Кооператив, Мультиплеер (RadminVPN / UDP), Сетка 50x50 px, Пол 100x100 px, Bang-Bang Управление и Главное Меню (Версия 2.3)

1. **Сетка Карты 50×50 px и Плиты Пола 100×100 px**:
   - Арена ($3600 \times 2400$ px) разделена на дискретную сетку $72 \times 48$ клеток размером $50 \times 50$ px.
   - Графика пола адаптирована под квадратные плиты $100 \times 100$ px ($36 \times 24$ плит), внутри каждой из которых расположены ровно 4 игровых клетки $50 \times 50$ px с четкими разделительными линиями и массивными контурными стыками. Нулевые дробные погрешности.
   - Все постройки (стены 50×50 px, алтари 100×100 px, обелиски 300×300 px) центрируются функцией `snap_to_build_grid` строго по узлам сетки, исключая зазоры при возведении баррикад.

2. **Очерченные Фундаменты Построек**:
   - Для Алтарей Крови ($100 \times 100$ px = $2 \times 2$ клетки) и Обелисков Разломов ($300 \times 300$ px = $6 \times 6$ клеток) добавлена визуальная подложка фундамента с контрастными угловыми маркерами. Игрок за Директора точно видит границы объектов и может плотно обстроить их стенами без зазоров.

3. **Бафф Построек от Прокачки «Панцирь»**:
   - Баррикады, Алтари и Обелиски получают прибавку к защите от каждого уровня улучшения `grade_carapace`: **+2.5 к плоской броне** и **+5% к сопротивлению физическому урону** за уровень.

4. **Уязвимость Обелисков и RL-Радар Босса**:
   - Урон наносится **только активному Обелиску** во время 20-секундного Инфернального Ритуала. Спящие обелиски полностью неуязвимы к атакам Босса.
   - Убран искусственный хардкодный приоритет (вес 240.0). Вектор наблюдений Босса расширен радаром обелисков (`obs[154..166]`): нормализованные координаты X, Y и бинарный флаг активности каждого из 4 разломов. Босс самостоятельно принимает решения на основе чистого Reinforcement Learning.
   - Награды Босса: успешная деактивация активного Обелиска дарует **+500 XP**, глобальный сбор кристаллов и моментальное лечение **+20% от максимального HP**.

5. **Bang-Bang Скорость и КД Рывка**:
   - Устранена инерция перемещения Босса: движение происходит либо на **100% максимальной скорости**, либо мгновенная остановка (0 px/s), что позволяет точно маневрировать между баррикадами и зонами поражения.
   - Базовый кулдаун рывка Босса сбалансирован до **5.0 секунд**.

6. **Исключение Перезапуска на Клавишу [R]**:
   - Клавиша `[R]` закреплена исключительно за игровыми действиями (призыв Големов тира 4 и `Ctrl+R` для алтаря 4 тира).
   - Перезапуск матча на экране Game Over перенесён на клавишу `[Пробел]`, выход в меню — на `[Escape]`.

7. **Стилизованное Главное Меню**:
   - Темное готическое главное меню с выбором режимов:
     - **«Играть за Директора • Против Босса ИИ»** (классический режим стратегии).
     - **«Играть за Босса • Против Директора ИИ»** (соло-выживание с управлением WASD + мышью).
     - **«Сетевая игра • Создать / Подключиться»**.
   - Поля ввода никнейма, селектор внешнего вида Босса и меню переназначения клавиш управления.

8. **Сетевой Кооператив и Мультиплеер (RadminVPN / UDP)**:
   - Легковесный сетевой драйвер `UdpDriver` на порту `45678` с поддержкой виртуальных локальных сетей RadminVPN (`26.x.x.x`).
   - Поддержка игры одного игрока за Директора, а остальных — за команду Боссов.
   - Таргетинг мобов: орда спавнится вокруг каждого живого игрока с персональной фиксацией цели, при этом мобы могут задевать союзников коллизией.
   - На павших игроков спавн мобов не происходит.
   - Механика воскрешения: на месте гибели союзника остаётся тело в падших доспехах с круговой зоной воскрешения (радиус 50 px). При нахождении живого соратника в зоне в течение 6.0 секунд союзник воскресает с 35% HP.
   - Спавн скелетов у Алтарей Крови масштабируется от общего числа игроков-боссов.
   - Распределение опыта: XP за кристаллы делится поровну между всеми живыми игроками; павший игрок продолжает получать равную порцию опыта, не урезая долю живых напарников.
   - Здоровье Обелисков динамически умножается на количество живых игроков-боссов.

## 16. Формула Брони Blizzard/Dota, Полноценный HUD Босса и Выбор 3 Карт Level-Up (Версия 2.4)

1. **Формула Физ. Резиста от Брони**:
   - Внедрена каноническая гиперболическая формула:
     $$\text{Множитель урона} = 1 - \frac{0.06 \cdot Б}{1 + 0.06 \cdot |Б|}, \quad \text{Снижение урона (Резист)} = \frac{0.06 \cdot Б}{1 + 0.06 \cdot |Б|}$$
   - Каждая единица брони $Б$ даёт ровно **+6% к базовому эффективному здоровью (EHP)** без перенасыщения и без обесценивания.
   - Отрицательная броня ($Б < 0$) плавно увеличивает входящий урон (до 2x при экстремальных дебаффах) без деления на ноль.

2. **Полноценный HUD для Игрока-Босса**:
   - Верхняя тактическая панель: текущее здоровье HP, полоса опыта XP до следующего уровня, точное значение брони с процентом физ. защиты (например, `6.0 (26.5% физ. защиты)`), статус готовности рывка и таймер матча.
   - 6 слотов оружия с иконками, уровнями (`1..8`, `MAX`, `+Lvl Limit Break`) и динамической маской кулдауна перезарядки.
   - 6 слотов пассивных реликвий с иконками и уровнями прокачки.
   - Тултипы при наведении курсора с описанием характеристик, скейлинга и условий эволюций.

3. **Интерактивное Окно Выбора из 3 Карт (Level-Up)**:
   - При повышении уровня игра переходит в тактическую паузу и выводит 3 уникальные карты из взвешенного пула с учётом синергий (эволюции, улучшения, новые виды оружия, реликвии, Limit Break).
   - Выбор доступен как кликом мыши по кнопке «ВЫБРАТЬ», так и быстрыми клавишами `[1]`, `[2]`, `[3]`.
   - Очередь уровней: если за один бой подобрано много кристаллов, игрок последовательно выбирает каждое улучшение.
   - ИИ Босса в режимах симуляции и игры за Директора продолжает делать автономный выбор на основе генетических весов и архетипа без задержек.
