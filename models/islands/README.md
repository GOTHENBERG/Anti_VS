# Папка обмена Островной Модели (Island Model)

Сюда Syncthing автоматически синхронизирует файлы чемпионов между устройствами:
- `island_<NAME>_boss.json`
- `island_<NAME>_director.json`

Каждые `--migrate-every` поколений движок экспортирует сюда лучшего агента текущего узла и импортирует чемпионов с других узлов.
